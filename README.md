## 四、结论与复习建议

1. **教育心理学 + 心理学基础约占 36%**，是最大板块：学习动机（成就动机、归因、自我效能感）、认知/建构主义学习理论、个性心理（能力、气质、性格）、心理发展理论（皮亚杰、维果茨基、埃里克森、柯尔伯格）几乎场场考。
2. **教育法律法规约占 15%**：教育法律关系、法律责任与救济（申诉/复议/诉讼）、《教师法》《义务教育法》《未成年人保护法》《学生伤害事故处理办法》是固定得分点，且常以案例不定项形式出现。
3. **教育学原理**：教师与学生、教育目的与方针、教育与人的发展（遗传/环境/教育/主观能动性）、教育学发展史（教育家与著作）稳定高频。
4. **班级管理与班主任工作、教师职业道德规范**每场都有，多为判断+案例分析，答题思路高度固定（关爱学生、尊重人格、不得体罚、家校合作）。
5. **时政与政策文件**明显升温：2019 年以前每场 0–1 题，2020 年后每场 1–6 题，2024 年 11 月起每场 6–9 题（新课标、“双减”、教育强国建设规划纲要等）。
6. 题型结构：2018–2024 年为 判断24+单选45+多选10+不定项8=87 题；2025 年起为 判断30+单选50+多选10+不定项8=98 题。

建议：先用「同类题合并」按题组学习（一个题组看懂即掌握一类题），再用「分类刷题」按高频知识点刷，最后用「模拟考试」限时自测，错题交给「艾宾浩斯复习」按 1/2/4/7/15/30 天自动安排。

## 七、功能
按模块/知识点/年份/题型刷题（顺序/随机）、历年真题整卷、模拟考试（限时 120 分钟自动评分）、同类题组视图、答案与解析、错题本（连续答对 N 次自动移出）、收藏、笔记、艾宾浩斯复习、学习统计、高频考点图表、全文搜索、深色模式；数据保存在浏览器本地，可在「设置与备份」中导出/导入 JSON。适配手机与电脑。
